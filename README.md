# AGE OF CHICS™ BY HYPERION

Standalone presentation app for the AGE OF CHICS deck.

Watch the slides, jump from the thumbnail strip, present fullscreen (F5), export a PDF, or open the original deck in your default app. The app checks for updates on startup before the main window opens; if the check cannot reach the server it continues as normal.
