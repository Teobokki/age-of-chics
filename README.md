# AGE OF CHICS™ BY HYPERION

Standalone presentation app for the AGE OF CHICS deck.

Watch the slides, jump from the thumbnail strip, present fullscreen (F5), export a PDF, or open the original deck in your default app. You can also open a PDF or presentation file (.pdf, .pptx, .ppt) from your PC; the last file is remembered and re-read from disk on the next launch so your edits show up. The app checks for updates on startup before the main window opens; if the check cannot reach the server it continues as normal.
