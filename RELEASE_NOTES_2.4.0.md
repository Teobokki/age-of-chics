# AGE OF CHICS™ BY HYPERION 2.4.0

Open a PDF or presentation file from your PC and view its slides in the same viewer (navigation, jump, present, export). The last file you opened is remembered and reloaded from disk the next time you start the app, so edits you make to that file show up automatically. Use Reload to re-read the current file on demand. If a presentation file can't be converted on this PC, export it to PDF and open the PDF instead.

If no file has been opened, the bundled deck is shown as before.
