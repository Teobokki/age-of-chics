# AGE OF CHICS 1.0.0

First release — a standalone presentation of the AGE OF CHICS deck.

- Title/home screen, then the 7-slide deck
- Next/previous, arrow keys, slide counter, and thumbnail jump
- Fullscreen present mode (F5, Esc to exit)
- Export the bundled PDF, or open the original deck in your default app
- Checks for updates on startup before the main window opens (continues if offline)
- Per-user Setup installer (no admin) and a portable exe
